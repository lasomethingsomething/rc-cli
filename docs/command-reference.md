# Command reference

The command table lives in the [README](../README.md#commands). This page has the full flag
lists and the binding-commands pointer.

```sh
rc profile --help
rc profile go --help
rc profile go generate --help
rc bindings --help
```

## Binding commands

`rc bindings` resolves, generates, and verifies extension bindings. The command group
provides `resolve`, `normalize`, `generate`, `verify`, `package`, `plan-release`, `check`,
and `update`. For schemas, flags, and local binding development, see
[docs/bindings.md](bindings.md).
